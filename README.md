# Эмулятор UNIX-оболочки — вариант №5

Проект по дисциплине «Конфигурационное управление».

## Этап 1. REPL

Графический прототип на Python/Tkinter. Заголовок окна строится из
реального имени пользователя и компьютера. Командная строка разбивается
по пробелам. Реализованы заглушки `ls`, `cd` и команда `exit`.
Неизвестные команды и неверные аргументы `exit` вызывают ошибку.

## Запуск

Требуется Python 3.10+ с Tkinter.

Windows:

```powershell
.\run.bat
```

Linux/macOS:

```bash
bash run.sh
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Примеры

```text
ls -l /tmp
cd /home
unknown
exit 1
exit
```

Для `ls` и `cd` на первом этапе выводятся названия команд и аргументы.
